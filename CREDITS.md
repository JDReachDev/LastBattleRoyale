# Credits

**Last Battle Royale** — JDReach (DarkReach).

## Based on

- **Last Stand** by **Kanade** — the original gamemode this project started from
  (round system, class/level system, squads, map config format).

## Third-party code included

These files are modified copies ("`_fix`" / "`_edit`") of entities from other Workshop addons.
They remain the work of their original authors; they are included only so the gamemode works
with its own balance changes.

| File(s) | Original addon |
|---|---|
| `entities/weapons/sg_medkit_fix`, `entities/weapons/sg_adrenaline_fix` | [Medkit and Adrenaline](https://steamcommunity.com/workshop/filedetails/?id=180842642) (Gmod4phun, Progsys, LordiAnders) |
| `entities/weapons/rust_supply_fix.lua`, `entities/entities/ent_supplysignal_fix`, `entities/entities/ent_supplydrop_fix` | [Legacy Rust Sweps](https://steamcommunity.com/workshop/filedetails/?id=702289635) / [Rust (Legacy) Entities Pack](https://steamcommunity.com/workshop/filedetails/?id=705904773) |
| `entities/entities/hb_main_implosionbomb_edit.lua` | [HBOMBS Base Pack](https://steamcommunity.com/workshop/filedetails/?id=668552230) |
| `entities/entities/cw_attpack_random_*` | [Customizable Weaponry 2.0](https://steamcommunity.com/workshop/filedetails/?id=349050451) (Spy) |
| `entities/entities/kevlar_armor`, `entities/entities/suit_ghillie` | [Arctic's Slightly Nicer Armor and Medkits](https://steamcommunity.com/workshop/filedetails/?id=494180444) (Arctic) |
| Colored chat messages in `gamemode/shared.lua` | Mors Quaedam (Facepunch forums) |

All weapons, vehicles, models and sounds used at runtime come from the required Workshop addons
listed in the [README](README.md#requirements) and belong to their respective authors.
